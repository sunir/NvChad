## Heuristics Search — Find SOPs and Resources First

Before starting any non-trivial task, search the heuristics library for relevant
methodology, agents, or SOPs:

    rag search "your task description"   # finds agents, SOPs, frameworks

The heuristics library contains 65+ domain specialist agents and systematic
methodologies (debugging, speccing, marketing, sales, architecture, etc.).

**When to search:**
- Starting a task you haven't done before
- Unsure which approach to take
- Looking for the right specialist agent
- Need a framework or SOP for the work

Don't guess. Search first, then decide.
